Broken Link Fix — Appointment Booked Email

Call-Booked Sequence · "Appointment Booked #2 – 24 Hours" template

Date: 2026-04-28 Platform: GoHighLevel (GHL) Status: Fixed
Issue
Meeting link not working
Root Cause
Merge tag used as href
Fix
Inline link in email body

What Went Wrong

In the Appointment Booked #2 – 24 Hours email, anchor text "Click here to join" was present in the body. To turn it into a clickable meeting link, GHL's merge tag {{appointment.meeting_location}} was pasted directly into the Link URL field of GHL's Add/Edit Link dialog.

What was set as the href
https://email-builder-prod.leadconnectorhq.com/%7B%7Bappointment.meeting_location%7D%7D

GHL's email builder URL-encoded the curly braces in the merge tag ({ → %7B, } → %7D), producing a literal, non-functional URL instead of resolving the dynamic meeting link at send time.

As a result, recipients who clicked "Click here to join" landed on a broken page — the merge tag was never substituted with the actual Zoom / meeting URL.

Root Cause Detail

Factor Detail
GHL behavior The Link URL field in GHL's email builder treats its value as a static URL. Merge tags entered there are URL-encoded rather than resolved before send.
Merge tag placement {{appointment.meeting_location}} must appear as plain text inside the email body — not inside an href attribute — for GHL to substitute it correctly.
Other emails in sequence The remaining call-booked emails handled this correctly by placing the merge tag directly in the body as a clickable text element, not through the Link URL dialog.

Fix Applied

The broken hyperlink was removed from "Click here to join". Instead, {{appointment.meeting_location}} was placed directly in the email body as inline text — consistent with how every other email in the same Appointment Booked sequence handles the meeting link.

Before (broken)
<a href="https://email-builder-prod.leadconnectorhq.com/%7B%7Bappointment.meeting_location%7D%7D">Click here to join</a>
After (fixed)
{{appointment.meeting_location}}
— rendered by GHL at send time as the actual meeting URL

When GHL sends the email it now resolves the merge tag to the real meeting URL, which the recipient can click directly.

Why This Fix Works

  • GHL resolves {{…}} merge tags that appear as body text at send time, substituting the actual value before the email leaves the system.
  • Merge tags placed inside an href attribute via the Link URL dialog are treated as static strings and URL-encoded, so they are never resolved.
  • Placing the merge tag in the body (rather than wrapping it in a separate hyperlink) mirrors the pattern used successfully in the other appointment-booked emails.
