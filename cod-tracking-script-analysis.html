Clients on Demand — Tracking Script Analysis

Investigation of tracking infrastructure on COD GoHighLevel funnels
Report Date: April 10, 2026

1. Script Under Investigation

The following tracking script was identified on Clients on Demand funnel pages:

<script>
var head = document.head;
var script = document.createElement('script');
script.type = 'text/javascript';
script.src = "https://t.clientsondemand.com/v1/lst/universal-script
    ?ph=ec35934759cf443f45e3f1f923b7c89b7bdffdf246ee9f2685813e4b5d1937d8
    &tag=!clicked
    &ref_url=" + encodeURI(document.URL);
head.appendChild(script);
</script>

2. Script Breakdown

The script dynamically injects a tracking pixel by creating a <script> tag and appending it to the page's <head>. It sends data to the tracking server at t.clientsondemand.com.

Parameters Collected

Parameter Value / Purpose
ph Hashed identifier — likely a campaign, funnel, or affiliate ID
ec35934759cf443f...d1937d8
tag !clicked — event tag indicating a click action occurred
ref_url The URL of the page where the script runs (tracks visitor origin)

Purpose

  • Tracking ad campaign performance (Facebook, Google, etc.)
  • Attributing leads/sales to specific marketing funnels
  • Retargeting visitors
  • Measuring which pages drive conversions
Assessment: This is standard marketing tracking technology, not malware — but it does track user behavior across funnel pages.

3. Hyros Connection Investigation

Hyros is an ad tracking and attribution platform designed for high-ticket businesses (coaches, course creators, agencies). It is popular in the info-marketing space that Clients on Demand operates in.

Key Question: Is this a Hyros script?

The script is branded under Clients on Demand's own domain (t.clientsondemand.com), not hyros.com. However, COD may be using Hyros as their underlying tracking infrastructure, or they've built a similar system internally.

Can Hyros Track Events Through Facebook?

Yes — Hyros works alongside Facebook's native pixel as a server-side attribution layer. It does not replace Facebook tracking.

How Hyros integrates with Facebook:

  • Tracks users across funnels using its own cookies/identifiers
  • Connects to Facebook's Conversions API (CAPI) to send server-side events
  • Helps attribute sales back to specific Facebook ads, even with iOS 14+ privacy restrictions

What Hyros Tracks That Facebook Can't Easily Do Alone

  • Long sales cycles (click today, buy 30 days later)
  • Phone call sales / offline conversions
  • Multi-touch attribution across platforms
  • Recurring revenue from subscriptions

5. How Hyros Tracking Works Without a Visible Script

Two likely scenarios explain how Hyros data appears without a script on the page:

Scenario A: Hyros Connected via Facebook's Backend (Most Likely)

Hyros can pull data directly from Facebook Ads Manager through API integration — no script on the page required.

Facebook Pixel (via GTM)
↓ fires events (PageView, Lead, Purchase, etc.)
Facebook receives events
↓ API connection
Hyros pulls data from Facebook API
↓ matches with own tracking
Hyros Dashboard shows attribution

In this model, Hyros "piggybacks" on Facebook's pixel data without needing its own script on every page.

Scenario B: COD Script IS a White-Labeled Hyros Implementation

The t.clientsondemand.com script may be a custom or white-labeled Hyros implementation. Larger Hyros customers sometimes get custom tracking domains to:

  • Avoid ad blockers
  • Brand it as their own
  • Keep tracking infrastructure private

6. Conclusion

Clients on Demand most likely uses Hyros's Facebook Ads API integration to pull attribution data, combined with their own custom tracking script (t.clientsondemand.com) for internal funnel tracking. The two systems sync via Facebook's Conversions API or a direct Hyros-to-Facebook API connection.

This explains why no hyros.com script is visible on the pages — Hyros doesn't require one when it's pulling data from connected ad platforms via their APIs.
