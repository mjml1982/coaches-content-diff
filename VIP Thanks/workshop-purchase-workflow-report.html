What Is "Quick Compose" in GoHighLevel?

GoHighLevel's email step inside a workflow gives you two ways to write an email:

Option What It Does When to Use
Quick Compose An inline email editor built directly inside the workflow step. You write the subject line and body right there — with basic formatting, custom values (merge tags), and a simple toolbar. No external template is needed. When no saved template exists, or the email is specific to this workflow and doesn't need to be reused elsewhere.
Create from Template Loads a pre-built, saved email template from your GHL email templates library — with full drag-and-drop layout, branded design, images, and columns. When you have an existing branded template saved and want to reuse its design across multiple workflows.
In plain terms: Quick Compose = writing the email directly in the workflow, like composing a plain email.
Create from Template = picking a pre-designed email layout you saved earlier and filling it in.

Since the original Workshop Purchase workflow's email was never saved as a reusable template in GHL, Quick Compose was the only practical option — and using it in the new workflow keeps both workflows consistent.
