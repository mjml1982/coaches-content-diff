Overview

A new Workshop Purchase (Non-VIP) automation workflow has been created and drafted in GoHighLevel with updated email and SMS copy. The workflow is functional, but a configuration difference was flagged compared to the original workflow: the email step uses Quick Compose instead of being built from a saved template.

Key Finding: The email action in this workflow was built using GoHighLevel's "Quick Compose" editor — a basic inline rich-text builder — rather than loading a pre-designed template. This deviates from how the original workflow was set up and may result in inconsistent branding and layout.

✅ Original Workflow — Create from Template

  • Pulls from a saved, branded email template
  • Global template updates propagate automatically
  • Consistent layout, fonts, and brand colors
  • Easier to audit and maintain

⚠️ New Workflow — Quick Compose

  • Email built directly in the workflow step editor
  • Basic rich-text only — no drag-and-drop template design
  • No automatic updates if brand changes
  • Harder to maintain across multiple workflows

Recommendations

1
Replace Quick Compose with a Saved Template

Open the email step in the new workflow, delete the Quick Compose content, and select "Create from Template." Choose the same base template used by the original VIP workflow (or create a Non-VIP variant of it).

2
Migrate the Drafted Copy into the Template

Port the new email copy (subject line, body, CTA) from the Quick Compose draft into the template builder so no content is lost.

3
Review & Publish After Fix

Once the email step is corrected, run a test contact through the workflow to verify email and SMS fire correctly, then publish.

4
Document Workflow SOP

Add a brief internal note / SOP that all new GHL workflows must use "Create from Template" for email steps — not Quick Compose — to prevent this from recurring.
